# 同樂班級大屏 — 使用與維運說明

單檔網頁（`index.html`）＋ Google Apps Script 後端（`Code.gs`）＋手機頁（`Mobile.html`）。
版本：v21（`Code.gs` v7）。最後更新：2026-11-18。

## 1. 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 大屏本體，在電子白板的 Chrome 開啟；三種模式：行政／教學／研習 |
| `Code.gs` | Apps Script 後端：同步、作業、平時成績、行事曆資料、手機頁 |
| `Mobile.html` | 手機編修頁（Apps Script 專案內檔名必須是 `Mobile`） |
| `opener/`、`檔案總管開啟器.zip` | 讓常用連結的 `D:\…`、`\\server\…` 路徑用檔案總管開啟（選用） |

## 2. 資料放哪裡

### 只存在這台電腦的瀏覽器（不上雲）
- **抽籤**：`cb.draw`（名單含姓名、已抽、歷史、指定設定）；三種模式各一份。
- **圖片、PDF、影片、畫板、貼圖**：IndexedDB `cb-files`。
- **版面**：`cb.layout`（教學）、`cb.layout.<模式>`。
- **投票、骰子、計時、噪音計**等小工具設定。
- 清除網站資料或換電腦就會消失；請用大屏的「備份／自動存檔」功能定期匯出。

### 同步到非公開試算表（`SHEET_ID` 那份）
| 分頁 | 內容 | 說明 |
|---|---|---|
| `大屏內容` | 清單、公告、倒數日、專案、常用連結、課表、備忘、當天四欄文字、手機頁卡片清單（`manifest`） | 欄位 `key,value,updatedAt,deleted`；同一筆以較晚修改者為準 |
| `homework` | 未繳作業 | 欄位 `key,日期,班級,身分,作業,未繳座號,updatedAt,來源,deleted`；`來源` 為 `board`（大屏）或 `form`（表單）；鍵＝`日期｜班級｜身分｜作業` |
| `score` | 個人平時成績 | 欄位 `key,日期,班級,座號,組別,分數,updatedAt`；每人每天一列，`分數`為當天累計；鍵＝`日期｜班級｜座號` |
| `公文` | 公文清單（由你自己的流程帶入） | 欄位 `承辦單位,承辦人,文號,主旨`；可另加 `狀態` 欄，填「已辦／已批／結案／歸檔」的列不計入未辦。**大屏只取件數與承辦單位，不取主旨、文號、承辦人** |
| `差假` | 差假紀錄（由你自己的流程帶入） | 欄位 `單位,姓名,表單,申請時間`；「申請時間」格式如 `起115-11-23(一) 15:00；訖115-11-23(一) 16:00；共計0日1時`。**大屏只取「今天在區間內」的姓名，不顯示假別**；加班、免刷卡單不算請假 |
| `Form Responses N` | Google 表單回應 | 由 `setupHwForm` 建立；只有 `HW_FORM_ID` 對應的那個分頁有效 |

> 行政模式的行事曆另外讀取 `TLPS-daily`（連結可檢視），僅供行政模式使用。

### 行政看板小工具（v8）
在「編輯版面」新增「公文未辦」「今日請假」兩個小工具即可。資料每 5 分鐘向雲端取一次；離線時顯示上次資料並標示時間；若取得的資料不是今天的，請假名單會顯示「等待更新」而不是舊名單。更新 `Code.gs` 後要「管理部署作業 → 編輯 → 新版本」才會生效。

## 3. 隱私原則
- 試算表與大屏**只存班級＋座號，不存學生姓名**。
- 抽籤名單（含姓名）只留在本機瀏覽器。
- 大屏畫面**不顯示個人分數**，只顯示大組總分；個人分數只在試算表或「成績」匯出的 CSV。
- 同步用的試算表請維持非公開；匯出的成績 CSV 請妥善保管。
- 教學／研習模式的行事曆來源若仍是個人行事曆，請改用專用行事曆（`CALENDAR_ID`）。

## 4. 班級固定名單
`一年忠班、二年忠班、三年忠班、四年忠班、五年忠班、六年忠班、特一、特二`

- 後端：`Code.gs` 的 `HW_CLASS_DEFAULT`；名單外的班級在作業與成績寫入時會被拒收。
- 前端：`index.html` 的 `SCHOOL_CLASSES`。
- 增減班級時兩處都要改，再執行一次 `fixHwFormClasses` 更新表單下拉。

## 5. Script Properties（Apps Script → 專案設定 → 指令碼屬性）
| 名稱 | 必填 | 說明 |
|---|---|---|
| `SHEET_ID` | ✔ | 非公開試算表 ID（網址 `/d/` 與 `/edit` 之間那串），值要貼在「值」欄，**屬性名稱不能被取代** |
| `TOKEN` | ✔ | 大屏與手機頁的通關密碼，請改成自己的長字串 |
| `CALENDAR_ID` | 選填 | 專用行事曆 ID；未設則讀預設行事曆（會帶出個人行程） |
| `HW_TAB` | 選填 | 作業分頁名稱，預設 `homework` |
| `SCORE_TAB` | 選填 | 成績分頁名稱，預設 `score` |
| `DOC_TAB` | 選填 | 公文分頁名稱，預設 `公文` |
| `LEAVE_TAB` | 選填 | 差假分頁名稱，預設 `差假` |
| `HW_FORM_ID` | 自動 | `setupHwForm` 建立表單後寫入 |

## 6. 部署與更新步驟
1. 把 `Code.gs` 整份貼進 Apps Script（不要用尋找取代改屬性名稱）。
2. 部署 → 管理部署 → 編輯 → 版本選「新版本」→ 部署。網址不變。
3. 存取權限選「任何人」（若選網域限定，網址會變成 `/a/macros/…`，大屏會連線失敗）。
4. 大屏「設定」填入 Apps Script 網址（`/exec` 結尾）與 `TOKEN`。
5. 首次建立表單：在編輯器執行 `setupHwForm`（**只執行一次**，重複執行會產生多份表單與多個 `Form Responses` 分頁）。
6. 更新班級名單後：執行 `fixHwFormClasses`。
7. 更新 `index.html`：直接覆蓋電腦上的檔案，重新整理。

## 7. 功能與同步行為摘要
- **同步**：每次編修約 1 秒內寫入，離線時排隊、連線後補送；大屏狀態列顯示「同步 HH:MM」。
- **未繳作業**：大屏登記 → `homework`；表單填寫 → 約 1 分鐘內出現在大屏；名稱相同者以較晚修改為準；大屏可回看歷史。
- **計分板**：「點座號給分」→ 該座號與其所屬大組同時加減分；大組分數＝組員分數加總＋整組手動加減；「歸零」只清大屏上的分數，不刪試算表紀錄；「成績」可匯出 CSV（總分／每日明細）。
- **手機頁**：網址為 Apps Script 網址加 `?page=m`，輸入 `TOKEN` 後可編修今日四欄、清單與公告、專案與常用連結、倒數日與課表。
- **常用連結**：`名稱 | 網址或路徑`；本機路徑需先安裝 `opener`，並在 Chrome 允許 `cbopen:` 協定。

## 8. 不會同步的內容
圖片、PDF、影片、畫板、貼圖、投票、抽籤、版面配置。手機頁不能補登作業。

## 9. 已知限制
- 在真實 Google 環境的行為（表單建立權限、學校 Workspace 政策）需實測確認。
- 防毒軟體可能攔截開啟器（`wscript` 呼叫 PowerShell）。
- `TOKEN` 預設若為 `tongle-2026`，請務必更換。
